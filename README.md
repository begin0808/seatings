# 🏫 專為學校教師打造的動態班級座位系統 · SeatPlan Portal

專為學校教師與導師日常教學打造的沉浸式班級動態隨機座位安排系統。提供兩組風格迥異但功能同樣強大的主題體驗：

1. 🪐 **小王子的星際旅行 (`seating.html`)**：溫暖浪漫的 B-612 星球宇宙風格，搭配星際座標、流星隨機排座動畫與星球導覽手冊 (`instructions.html`)。
2. ⚡ **霍格華茲魔法學院 (`seating_hogwarts.html`)**：莊嚴神秘的四大學院大廳與古典羊皮紙風格，搭配分類帽分發儀式與魔法指南 (`instructions_hogwarts.html`)。
3. ✨ **主題入口大廳 (`index.html`)**：教師入口大廳，提供雙主題傳送門、動態 Canvas 粒子光效與核心功能介紹。

## 🌟 核心特色

- 🔢 **免名單！純座號快排（專為教師現場排座設計）**：
  - 老師不想匯入 Excel 名冊時，直接設定座號範圍（如 1~35 號），支援快捷人數鍵（25人、30人、35人、40人或配合課桌數）。
  - **各班缺號／不排座超便利處理（轉出、休學等）**：
    1. **文字快速過濾**：輸入 `3, 18` 即刻自動剔除缺號。
    2. **視覺化點擊剔除**：直接在號碼球矩陣點選任意座號，秒切換「排座／❌ 缺號排除」，所見即所得，防呆又直覺！
- 📊 **Excel 智慧名冊匯入/匯出**：支援標準 `.xlsx` 班級名冊匯入（姓名與座號），亦可將最新排定的座位表一鍵匯出為乾淨格式的 Excel 表格。
- 📐 **自訂行列矩陣**：自由設定 1~15 直排、1~20 橫列的座位空間，輕鬆應對大班、小班與不同教室格局。
- 🚫 **損壞與空位管理**：點選座位即可標記為「猴麵包樹 (🌱)」或「蜘蛛網禁區 (🕸️)」，系統隨機排座時自動避開。
- 🔒 **100% 純前端離線隱私**：全班學生資料與演算法完全在瀏覽器本地運算，免上傳伺服器，嚴格保護學生個人隱私。
