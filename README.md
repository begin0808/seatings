# 🎯 動態隨機座位系統 · SeatPlan Portal

為教師、活動策劃與團隊主管打造的沈浸式隨機座位安排系統。提供兩組風格迥異但功能同樣強大的主題體驗：

1. 🪐 **小王子的星際旅行 (`seating.html`)**：溫暖浪漫的 B-612 星球宇宙風格，搭配星際座標、流星隨機排座動畫與星際導覽手冊 (`instructions.html`)。
2. ⚡ **霍格華茲魔法學院 (`seating_hogwarts.html`)**：莊嚴神秘的四大學院大廳與羊皮紙古典風格，搭配分類帽抽籤儀式與魔法指南 (`instructions_hogwarts.html`)。
3. ✨ **主題入口大廳 (`index.html`)**：統一入口，提供雙主題卡片傳送門、動態 Canvas 粒子光效與核心功能介紹。

## 🌟 核心特色

- 📊 **Excel 智慧匯入/匯出**：支援標準 `.xlsx` 班級名冊匯入，自動讀取姓名與座號。
- 📐 **自訂行列矩陣**：自由設定 1~15 排、1~20 列的座位空間，適應各種教室與會議室。
- 🔄 **前後視角反轉**：一鍵切換「教師前視角」與「學生面向講台視角」，投影展示更直覺。
- 🔒 **100% 純前端離線私隱**：名冊與演算法完全在瀏覽器本地運算，免上傳伺服器。
